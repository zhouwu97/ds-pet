# Codex · ds鲸鲸娘

当前修复版使用 Work Pets v2 精灵图布局。

| 项目 | 数值 |
| --- | --- |
| 图片 | `jingjing-spritesheet.png` |
| 格式 | RGBA PNG，透明背景 |
| 完整尺寸 | 1536 × 2288 像素 |
| 网格 | 8 列 × 11 行 |
| 单格尺寸 | 192 × 208 像素 |
| 有效帧 | 73 张：57 张动作帧 + 16 张方向帧 |

“73 张”指有效图片数量，不代表 73 FPS。前 9 行为动作，后 2 行为方向素材；请保持整张图的尺寸、格子位置与透明通道。

## 使用

1. 下载完整的 `jingjing-spritesheet.png`。
2. 在支持 Work Pets v2 的 Codex / ChatGPT Work 客户端中，通过 Pets 插件导入已有精灵图，并选择该宠物。
3. 桌面仍显示旧素材或空白时，可在「Mini 与虚拟宠物」设置里刷新并重新选择宠物。

动画预览展示素材中的动作；实际客户端会根据状态选择动画，未必逐一循环全部动作。方向帧是否启用取决于客户端逻辑，本素材不保证普通鼠标移动会触发视线跟随。

`asset-info.json` 是素材信息与校验值，供核对使用。
